MIGRATE

PURPOSE
Prepare owner authority, apply Flyway, validate and finish schema authority.

USAGE
  [verify] make migrate help

VARIABLES
CONTAINER selects the engine (default podman). FLYWAY_NETWORK_ARGS selects its
network. PLZL_DATABASE_URL and FLYWAY_URL/FLYWAY_USER/FLYWAY_PASSWORD are
environment inputs.

WHEN
Run when preparing the authorized fresh database or applying an owned
migration.

BOUNDARIES
Mutates the selected database. Requires the owner PLZL_DATABASE_URL and Flyway
connection inputs; the fresh schema is not a customer-data upgrade.

EVIDENCE
Flyway migrate/validate and both schema authority checks pass.

EXAMPLES
  [verify] make migrate help
  [static] make migrate
